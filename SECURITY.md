# Política de Segurança

## Regras operacionais

- Usar conta nominal com `sudo`; `root` fica reservado para recuperação.
- Não publicar SSH, qBittorrent, Docker ou painéis administrativos.
- Expor somente o serviço estritamente necessário, por HTTPS, após testes.
- Validar chave SSH antes de desabilitar senha.
- Não registrar senhas, tokens, chaves privadas, IP público ou dados de mídia.

## Reporte responsável

Não abra issues públicas com detalhes de vulnerabilidades ou dados sensíveis. Use o contato do mantenedor no perfil GitHub.
